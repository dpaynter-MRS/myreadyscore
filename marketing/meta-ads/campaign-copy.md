## Suggested first test

- Run all three creatives in one ad set with equal starting budgets.
- Keep audience, placements, copy, CTA, and landing page consistent so the creative concept is the main variable.
- Evaluate completed assessments as the primary outcome; use click-through rate and landing-page views as diagnostic metrics.
- Do not select a winner from very small samples. Allow enough delivery for each creative to receive meaningful exposure before making changes.

## Reels/Stories setup notes

- Upload the matching 1080×1920 vertical creative for Reels and Stories placements rather than allowing an automatic crop of the feed image.
- Use the same primary text, headline, CTA, and tracked URL as the corresponding feed ad.
- Keep Meta's native `Learn More` CTA enabled; the artwork intentionally contains no imitation button.
- These are static vertical creatives. They can be turned into short motion ads later by animating the score gauge, checklist marks, and headline reveal.
